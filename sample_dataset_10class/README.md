# Sentinel Gujarat Police CCTV AI - 10-Class Verified Dataset Sample
This directory contains 100 verified 10-class annotated CCTV frames from Gujarat Police cameras, including:
- 71 hand-annotated ground truth frames from active CCTV junctions (Cam 01 Chimanbhai Bridge)
- 29 diverse twilight, night-sodium, and rush hour frames from Ahmedabad & Gandhinagar junctions

### Standardized 10-Class Indian Traffic Taxonomy
0: pedestrian
1: car
2: two_wheeler
3: heavy_machinery
4: emergency_vehicle
5: van
6: truck
7: bus
8: auto_rickshaw
9: others
